# Attendance Checker Laravel

## Description
Attendance Checker is a web-based application built with **Laravel** to manage student attendance.  
This project includes authentication for different roles (Teacher, Admin, Student) and allows Teachers to mark and view attendance records.

## Features
### Fully Functional
- **Teacher Role**
  - Mark student attendance
  - View attendance records

### Pending / Work in Progress
- **Admin Role**
  - Manage students (CRUD)
  - View overall attendance
- **Student Role**
  - View their own attendance
